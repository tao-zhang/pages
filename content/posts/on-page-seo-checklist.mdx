On-page SEO isn't a mystery — it's a short list of specific things, done
consistently, on every post. Here's the checklist we run before anything
here goes live.

## Before you write

1. **Pick one primary keyword per post.** Trying to rank for three things
   at once usually means ranking for none of them. If you don't have paid
   keyword tools, see our guide to [keyword research without paid
   tools](/blog/keyword-research-without-paid-tools).
2. **Match search intent, not just the keyword.** Someone searching "how
   to write a meta description" wants a how-to, not a history of meta
   tags. Structure the post as the answer they're expecting.

## The title and metadata

3. **Title tag includes the primary keyword**, ideally near the front, and
   stays under ~60 characters so it doesn't get truncated in results.
4. **Meta description is written, not auto-generated**, and gives someone
   a reason to click. See [how to write a meta description that gets
   clicked](/blog/how-to-write-a-meta-description) for a full breakdown.
5. **URL slug is short and readable** — the keyword phrase, not a string
   of stop words or a date stamp.

## Structure

6. **One H1 per page** (usually the title itself, handled automatically by
   most blog templates) and a logical H2/H3 hierarchy underneath it — don't
   skip heading levels just for font size.
7. **Headings describe what's actually in that section**, so both readers
   skimming and search engines parsing the page get an accurate map.
8. **Short paragraphs and scannable formatting** — bullet lists, bolded
   key terms, no walls of text.

## Links

9. **At least 2–3 internal links** to relevant existing posts — this
   helps search engines understand your site structure and keeps readers
   moving instead of bouncing. See our [internal linking
   guide](/blog/internal-linking-for-seo) for a system that scales.
10. **External links only where they add credit or clarity** — linking to
    the primary source instead of restating it secondhand.

## Images and performance

11. **Every image has descriptive alt text** and a reasonably compressed
    file size — page speed is a ranking factor, and Core Web Vitals
    matter more than most writers realize. More on that in our [Core Web
    Vitals explainer](/blog/core-web-vitals-for-non-engineers).

## Last check

12. **Read it as the searcher, not the writer.** Does this page actually
    answer the query that would bring someone here? If the honest answer
    is "sort of," it's not ready yet.

Run this list on every post before it ships — it takes five minutes and
it's the difference between content that can rank and content that just
exists.
